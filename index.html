Descripción del proyecto

El proyecto consiste en la creación de un sitio web para una academia online llamada Conquer Academy.
La web deberá estar compuesta por diferentes páginas conectadas entre sí mediante enlaces relativos,
manteniendo una estructura clara, semántica y ordenada.

El objetivo principal no es el diseño visual, sino demostrar una buena organización del contenido, un uso
correcto de las etiquetas HTML5 y una navegación coherente entre todas las vistas del sitio.
